# Getting Started with ThinkRail

This guide will walk you through installing ThinkRail and getting your first AI-assisted coding session running.

## Installation

### macOS / Linux

Open your terminal and run:

```bash
curl -fsSL https://thinkrail.ai/install.sh | bash
```

### Windows

Open PowerShell and run:

```powershell
irm https://thinkrail.ai/install.ps1 | iex
```

## First Steps

1. **Launch ThinkRail** — After installation, launch the app from your applications menu
2. **Create a Workspace** — Click "New Workspace" and select a Git repository
3. **Start Chatting** — Open a chat tab and start asking questions!

## Example Session

Here's a quick example of what you can do:

```
You: Create a React component that displays a user profile card

ThinkRail: I'll create a UserProfileCard component for you...
```

## Tips for Best Results

- **Be specific** — The more context you provide, the better the results
- **Use the spec graph** — Document your architecture decisions for consistent AI assistance
- **Iterate** — Don't expect perfection on the first try; refine your requests
