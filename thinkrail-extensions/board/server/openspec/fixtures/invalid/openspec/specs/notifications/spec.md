# notifications Specification

## Purpose

Tell customers about their orders through the channels they chose when they signed up.

## Requirements

### Requirement: Email channel
The system SHALL send order updates by email.

#### Scenario: an order ships
- **WHEN** an order ships
- **THEN** the customer gets an email

### Requirement: SMS channel
The system SHALL send order updates by SMS.

#### Scenario: an order ships
- **WHEN** an order ships
- **THEN** the customer gets a text message
