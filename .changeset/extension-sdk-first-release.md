First release of the ThinkRail extension SDK, carrying extension API 1.0: `defineServerExtension` and `defineWebExtension`, type declarations for the components ThinkRail shares with extensions, and `thinkrail-extension build`, which bundles a web half onto the app's React and builds its prefixed stylesheet. Ships with the Palette sample extension.
