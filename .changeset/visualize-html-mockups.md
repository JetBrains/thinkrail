Add static HTML UI mockups to the `visualize` tool: `type: "mockup"` with `html` (or `before` + `after`)
and an optional `viewport`, plus an optional `html` mockup per comparison option. In the terminal each
mockup is saved as a self-contained file and shown as an "Open in browser" link.
